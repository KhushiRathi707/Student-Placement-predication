# 🎓 Student Placement Prediction System

A Machine Learning based web application that predicts whether a student is likely to get placed based on academic and personal information.

The project is developed using **Python, Machine Learning, Django, HTML and CSS**.

---

## 📌 Project Overview

The Student Placement Prediction System takes different student details as input and uses a trained Machine Learning model to predict the student's placement status.

The system is designed as a Django web application with a simple and user-friendly prediction interface.

- Stream

- Hostel Status
- History of Backlogs
